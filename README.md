# RimWorld Mod & Load Order Manager (Rust Desktop)

Высокопроизводительный нативный менеджер модов и порядка загрузки RimWorld на Rust с аппаратным ускорением графики (`eframe` / `egui`).

## Ключевые возможности:
- ⚡ **Топологическая сортировка модов**: учёт встроенных метаданных About.xml, зависимостей, правил сообщества и каноничного порядка (Core, Royalty, Ideology, Biotech, Anomaly, Odyssey).
- 🖼 **Оптимизация текстур в BC7 DDS**: пакетная конвертация PNG/JPG в сжатый Direct3D формат с генерацией мипмапов на многопоточном движке Rayon с ограничением CPU (75% по умолчанию).
- 🩺 **Анализ вылетов (CTD) и логов**: автоматическая диагностика ошибок в Player.log / Player-prev.log с генерацией подробного промпта для Google Gemini в 1 клик.
- 🌐 **Поиск переводов в Steam Workshop**: поиск локализаций для конкретного мода или пакетный поиск для всей сборки с 1-клик подпиской через нативный Steam API (`steam_api64.dll`).
- 🗑 **Очистка и отписка**: безопасное удаление модов-переводов с защитой базовых модов и официальных DLC.

## Сборка и запуск:

### 1. Требования
- Установленный [Rust toolchain](https://rustup.rs/) (версия 1.78+)
- Windows 10/11 x64 (также поддерживается Linux / macOS)

### 2. Компиляция релизной версии:
```bash
cargo build --release
```

Готовый бинарник будет находиться в:
```text
target/release/rimworld-mod-manager.exe
```

### 3. Быстрый запуск:
```bash
cargo run --release
```
