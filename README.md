# RimWorld Mod Manager

Менеджер модов и порядка загрузки для RimWorld 1.6 (Unity) и 1.7 (Waylith). Написан на Rust, интерфейс на egui. Работает под Windows.

*Mod and load order manager for RimWorld 1.6 and 1.7 (Windows): load order sorting with RimSort community rules, mod categories, dependency checks, translation search on Steam Workshop, DDS texture optimizer, Player.log analyzer. The interface is available in Russian and English.*

## Скачать

Готовая программа лежит в разделе **Releases** этого репозитория. Скачайте `rimworld-mod-manager.exe` и запустите — установка не нужна.

## Что умеет

- **Список модов.** Включение и выключение, перемещение (в том числе мышью, по одному или группой), поиск, категории по содержимому мода (расы, фракции, постройки, оружие, QoL и т.д.) с фильтром. Предупреждения о зависимостях, несовместимостях, копиях одного мода и модах без поддержки текущей версии игры.
- **Сортировка.** Учитывает About.xml (зависимости, `loadAfter`/`loadBefore`, блоки `*ByVersion`) и базу правил сообщества RimSort, которую можно скачать или импортировать из RimPy.
- **Сохранение ModsConfig.xml** с бэкапом. Моды, которых нет на диске, при сохранении не теряются. В окне «История» можно вернуть порядок из любого из 30 последних сохранений.
- **Переводы.** Поиск переводов сразу для всех активных модов: показываются только переводы, в названии которых есть название мода и выбранный язык; подписка на отмеченные одной кнопкой. Можно искать и для одного выбранного мода. Удаление переводов выбранного языка — с подтверждением и в Корзину.
- **Оптимизатор текстур** (для 1.6 и старше). PNG/JPG конвертируются в DDS: BC7 для текстур с прозрачностью, BC1 для остальных, с мипмапами. Все созданные файлы записываются в журнал, поэтому откат удаляет их полностью. На 1.7 конвертация не нужна: игра сжимает текстуры сама. Вместо неё есть сброс кэша текстур игры.
- **Анализатор логов.** Разбирает Player.log обоих форматов (1.6 и 1.7), ищет моды-виновники и готовит текст запроса для ИИ.
- **Запуск игры** с параметрами под нужную версию.
- **Новые версии.** Раз в день программа проверяет релизы на GitHub и показывает плашку рядом с версией. Сама ничего не скачивает; проверку можно выключить в настройках.

Настройки, кэш и бэкапы хранятся в `%LOCALAPPDATA%\RimWorldModManager`.

## Сборка

Нужен [Rust](https://rustup.rs/) 1.87 или новее.

```bash
cargo build --release
```

Готовая программа: `target/release/rimworld-mod-manager.exe`.
